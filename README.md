## Shipped

- **[Log Analyzer](https://github.com/BytesFromToby/Log_breakdown)**: merges device logs from five formats into one timeline, strips the noise and writes the diagnostic report. Pure Python 3 and Tkinter, no outside dependencies.
- **[Plumbline](https://github.com/BytesFromToby/plumbline)**: runs a build the way a job site does. An architect writes the spec, a foreman breaks it into steps, a builder does the work, and an inspector who never saw the build checks it against the spec. Eight skills, plus two that run the whole job unattended.
- **[Polis](https://github.com/BytesFromToby/Polis)**: a strategy game set in an ancient Greek city-state. Twenty-eight AI factions bargain with you in live conversations, and a rules engine checks every deal before it touches the game. 638 tests pin the behavior.
- **[Banana or No Banana](https://github.com/BytesFromToby/BananaOrNoBanana)**: a game show between two AIs. One holds a box and makes a claim about the banana inside, true or false. The other guesses from the conversation the two have.
- **[RepoRouter](https://github.com/BytesFromToby/RepoRouter)**: reads each GitHub issue on a small local model, checks the claim against the repo's own docs, then replies, labels, closes, or hands it to a person. Guardrails pinned by pytest.
- **[The Auditor](https://github.com/BytesFromToby/nih-application-auditor)**: holds an NIH grant application against NIH's own published rules and cites the exact rule for every finding, before a reviewer ever reads it.
- **[Groundwork](https://github.com/BytesFromToby/Groundwork)**: a research agent that keeps a ledger and reads its own past runs first, so nothing gets pitched twice.
- **[Walkdown](https://github.com/BytesFromToby/Walkdown)**: checks an AI skill before anyone runs it. It reads everything the AI would read, lists each problem with the exact file and line, and leaves the decision to the person.
